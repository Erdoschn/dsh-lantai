# 兰台 · dsh-lantai

**给 DeepSeek Harness 加一座档案库：把一次会话里踩出来的经验，变成下一次会话开头就带着的东西。**

兰台不生产知识——它审。写的是 agent，管档案的必须是另一个程序，因为写的人会偷懒、会写一堆正确的废话、偶尔还会顺手写上"直接开管理员权限就行"。

```
agent 交出经验 ──► 兰台·录 过闸门 ──► ~/.dsh/skills/<name>/SKILL.md
                        │                    │
                        └─ 拒收：没写怎么验证、没说边界、夹带危险授权、重名
                                             │
                 下一次会话，harness 自动把这份目录注入给 agent ◄─┘
```

## 为什么需要它

Agent 每次开新对话都是完全失忆的。今天为了绕一个环境坑试错半小时，明天换个会话，同样的坑再来一遍。

人类团队把这种东西写进 README、写进交接文档。Agent 不会——除非有人在它收工时把话截下来、审一遍、存进一个下次会自动加载的地方。

## 五个工具

| 工具 | 卡片名 | 干什么 |
| --- | --- | --- |
| `skill_distill` | 兰台·录 | 交出一条经验；过闸门（命名、查重、必须有验证方式与边界、禁止危险授权）才落盘 |
| `skill_catalog` | 兰台·索 | 列出已有 skill、复核等级、下次复核时间；写入前查重 |
| `skill_audit` | 兰台·校 | 按复核阶梯算出哪些到期，重新过闸门，列出该跑的验证命令；不执行任何命令 |
| `skill_attest` | 兰台·勘 | 核对完盖章：`reviewedAt` 更新、等级 +1，下一次复核间隔自动拉长 |
| `skill_retire` | 兰台·削 | 归档（**不删除**）：先出示确认卡片，同意后移到 `skills.retired`，并留下 `RETIRED.md` 记录原因 |

## 60 秒上手

```console
# 1. 装进 profile（本机路径或 npm 包都行）
dsh plugin install /path/to/dsh-lantai

# 2. 在 profile 里配一行（默认已写进 cordis.patch.yml）
```

```yaml
- id: lantai
  name: 'dsh-lantai'
  config:
    skillRoot: '~/.dsh/skills'
    allowReplace: false
    nudge: true
```

重启一次，然后正常干活。agent 会在收工时自己调用 `skill_distill`，你只需要看闸门判得对不对。

## 闸门规则

一条 skill 会被注入到此后**每一个**匹配的会话里，所以收进来之前必须过关：

| 类别 | 规则 |
| --- | --- |
| 形状 | name 必须 kebab-case；description 必须具体到能据此决定要不要加载 |
| 实质 | 必须有「验证」小节且含一条可执行命令；必须有「边界」小节；正文要有具体路径或命令，不能是"要小心" |
| 安全 | 正则拒收：提权（`danger-full-access`）、关沙箱/审批、token 进 URL、正文里出现真实 token、强推、直推默认分支、管理员级凭据、"无需验证" |
| 唯一 | 重名拒绝；覆盖需显式 `replace: true` 且配置允许，旧文件自动备份 `.bak` |

拒收时逐条说明原因，且**一个字节都不写**。

## 复核阶梯

间隔由「已经过几次复核」决定，不是由日历决定——否则一核对完计数就归零，永远停在第一档。

| 阶段 | 间隔 | 该做什么 |
| --- | --- | --- |
| 0 | 7 天 | 轻查：验证命令还通得过吗 |
| 1 | 14 天 | 复查 |
| 2 | 30 天 | 环境复核：版本、路径、开关变了没 |
| 3 | 60 天 | 价值复核：有没有被更好的做法取代 |
| 4 | 90 天 | 成本复核：命中率如何，还值得占上下文吗 |
| 5 | 180 天 | 终审：重写、收缩，或删除 |

逾期超过 180 天，审计会建议归档——**但永远不会自动删**。

## 安全边界（请认真读）

兰台是**便捷层和质量管理**，不是安全边界：

- 它跑在 harness 进程里，**拦不住** agent 用 shell 直接写 `~/.dsh/skills`
- 它写入工作区之外，所以它比受限沙箱里的 agent 权限更大，而非更小
- 它能做的是：让"走闸门"成为默认路径、让每次写入留痕、让销毁变成归档
- 真正的强制在别处：token 的 scope、GitHub 的 rulesets、DSH 的沙箱与审批

## 它和别的"agent 记忆"方案差在哪

大多数方案追求"记得越多越好"。兰台的立场相反：**会拒收的沉淀器**。一条陈旧或错误的 skill 会被注入到之后每个会话，所以垃圾不是没用而已，它是持续的成本。因此这里有闸门、有查重、有复核阶梯、有归档而不是删除。

## 开发

```console
npm test        # 63 项：契约 / 闸门 / 阶梯 / 工具 / 归档
npm run check   # 语法检查
```

零运行时依赖，Node 20.11+。`test/contract.test.mjs` 里有一个用 Proxy 模拟 Cordis 的假上下文——访问未声明的服务会抛异常，这个测试保证了插件不会在 `apply()` 阶段静默失效。
